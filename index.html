EUNBYUL:~/sail-lab$ cat PRINCIPLES.md
  1. 작성·검토 분리 — 교정팀이 다듬은 글을 심사팀이 깨끗한 눈으로 본다
  2. 첨삭은 나누지 않는다 — 문체 일관성은 병렬화할 수 없다
  3. 스킬 = 팀 SOP — 절차는 매뉴얼로, 역할은 에이전트로 분리 관리
  4. 경량 경로 — 작은 일에는 팀을 소집하지 않는다
  5. 품질은 실전으로 평가 — PI 만족도·반려율·실제 심사 적중률로 팀을 조정한다
  6. 지어내지 않는다 — 인용·실적·규정은 실재 확인된 것만
  7. 비밀유지는 구조로 — 외부 심사 원고·학생 데이터는 로컬 전용, 지식베이스와 섞지 않는다
